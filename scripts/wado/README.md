# 漢字穴埋め（和同開珎）

自由に遊ぶ → 試作&製作中 → 和同開珎から、日本語の問題で遊べます。「はじめる」から1問生成し、ヒント・解答例を確認できます。回答入力・採点はありません。

## 現行Web版の操作（2026.10.27.62）

- 難易度・語数・文字サイズは、遊ぶ画面の「設定」から変更します。
- ヒントは3段階のボタンと「もう少しヒント」で表示します。印刷用の個別ヒント選択が、遊ぶ画面のヒント段階を上書きすることはありません。
- 解答例を開くと中央の漢字と成立する熟語を表示し、再び隠せます。前の問題・問題一覧・続きからの再開に対応します。解答表示済みは正解・完成の判定ではありません。
- 問題表示中の「印刷する」は、その問題を選択済みでA4プレビューに開きます。一般の印刷入口で未選択の場合は「印刷する問題を選ぶ」から選択へ進めます。
- 既存の `np-wado-v1` を共有し、保存問題・印刷設定を自動削除しません。

## 辞書と出題

- 難易度10段階と、熟語2・3・4個を独立に選べます。問題の難易度は語彙の使用頻度で分け、文章ヒントの3段階とは独立しています。旧保存問題の選択肢・読みは互換性のため保持します。難易度は目安で、個人の馴染みや臨床的な評価を示しません。
- 上・左は「周り→中央」、右・下は「中央→周り」。2語は上と右、3語は左または下を追加、4語は全方向を使います。
- 手作業の出題リストで制限せず、3系統から抽出した **87,353表記**をすべて処理します。表記・ひらがな読みが2系統以上で一致する **41,858語**を出題に採用します。JMdict必須ではなく、SudachiDictとJUMANの一致も採用します。
- **42,468表記は保留**（一系統だけ41,984、読みの一致を確認できない484）、**3,027表記は出題対象外**です。対象外は、現在の抽出条件で現代の独立した語の読みを確認できない表記です。保留・対象外・辞書未確認のどれも「実在しない」「誤答」という断定ではありません。
- `wado-audit.tsv` に全87,353表記の採用・保留・対象外、理由、採用読み、出典系統、元の収録系統と読み候補、頻度・難度を記録します。全件が重複なく一つの状態になった時点を今回の処理の完了条件とします。
- wordfreq 3.1.1の表記頻度から、Zipf 3.5以上をrank1、2.8以上をrank2、それ以外をrank3とします。頻度ゼロは語の不存在を意味せず、難しい側に置きます。難易度は解答例の頻度とヒント量の目安で、個人差や別解では変わります。
- `preferred-readings.json` の確認済みの読みは、2系統以上で一致した場合だけ優先します。解答例の表記と読みを組み合わせて照合します。
- **別解を許容します。** 生成は唯一解を条件にせず、解答例の2〜4熟語が成立することを検証します。画面・解答用紙は「解答例」と表示し、他の漢字でも全熟語が成立すれば正解と案内します。読み・選択肢は解答例のヒントです。画面ではヒント・解答例を閲覧して遊べます。回答入力・自動採点はありません。
- 手元の問題では、87,353表記の収録範囲で成立する候補と各熟語・出典をすべて表示します。0件は未確認であり、答えが存在しないとの判定ではありません。人名・地名・新語・範囲外の漢字を含む日本語全体を網羅しているとは表示しません。
- 保存上限500問。`np-wado-v1` は引き続きバックアップ対象です。保存形式のversion1/2を読み、旧問題の読み・難度は `legacy-v1.json` の旧2,045語で検証・表示します。この旧リストは新規出題の制限には使いません。旧データを書き換えたり削除したりしません。
- 問題・解答例は別々にA4印刷（1/2/4/6問）。画面で開いた解答・検索結果は問題用紙に混入しません。

## 未収録の判断基準と有限の監査

普遍的な「辞書未収録＝存在しない語」という基準は、今回調べた範囲では見つかりませんでした。JMdictの[公式編集方針](https://www.edrdg.org/wiki/Updated_editorial_policy.html)も、表記・読み・用例・他資料を総合し、Google件数の不確かさを指摘しています。ネット結果0件を否定判定にせず、無制限の探索は行いません。

商用の加工・配布ができる **CC BY 4.0** の[国立国語研究所『日本語教育のための基本語彙調査』（1984）データ](https://mmsrv.ninjal.ac.jp/bvjsl84/)を固定した外部比較基準に採用しました。`2_nihongokyoiku02.xlsx` のF列が漢字二字の表記は重複除去で2,590件。そのうちG列の送り仮名が空の行を持つ **2,575表記** を照合対象にし、送り仮名が別記された語幹だけの15表記も対象外として記録します。辞書との一致結果によって対象を削ったり、原資料の表記を自動修正したりしません。数詞・古い表記や資料中の疑わしい表記も残ります。

`wado-coverage.json` と `dictionary-report.json` に全比較対象、辞書収録と出題採用の結果、未確認表記を記録します。これは **1984年の当該調査の二字見出しとの一致** であり、「現代の日常語全体の網羅率」「正しい熟語の正解集合」ではありません。未確認語は誤答にしません。全件を照合し、出典・範囲・原資料ハッシュ・対象外の条件を記録した時点で、今回の調査を終了します。

CEJC・BCCWJの調べた語彙表は商業使用が要相談・再配布不可のため、今回は取り込んでいません。wordfreqは頻度の補助だけで、語の実在の票にはしません。

## 再現・更新

`wado-data.json` と `sources.lock.json` に提供元・版・日付・URL・入力ファイルのSHA-256を記録しています。JUMANは固定コミット、Sudachiは20261015、JMdictは3.6.2+20261019180022、wordfreqは3.1.1です。JUMANの日付は辞書先頭の版記載で、取得日や最新性を表すものではありません。

ビルド時だけ `python3 -m pip install -r scripts/wado/requirements-build.txt` を使います。ロックのURLからJMdict/Sudachiを取得し、JUMANを指定コミットで取得した後：

```sh
python3 scripts/wado/build-dictionary.py \
  --jmdict /absolute/path/jmdict-eng.json.zip \
  --sudachi-small /absolute/path/small_lex.zip \
  --sudachi-core /absolute/path/core_lex.zip \
  --juman /absolute/path/juman \
  --basic-vocabulary /absolute/path/2_nihongokyoiku02.xlsx
python3 scripts/check-nanpure-wado-dictionary.py
node scripts/check-nanpure-wado.cjs
```

SmallのV0とCoreのV1は別々のCSVとして公開仕様の共通語彙カラムを読みます。バイナリ辞書を混ぜて利用する処理ではありません。ヘッダー・列数・ZIP整合性・内容ハッシュが違えば、成果物を上書きする前に停止します。

**少なくとも月1回**、および語彙変更時に更新を確認します。新しい版の利用条件を再確認してからロックを手動更新し、`dictionary-report.json` の除外語・難易度変更・読みの差分をレビューしてください。既存保存問題が再検証で不成立になる場合は旧辞書保持または明示的移行が必要です。利用中の保存を自動削除しません。新データでも既存保存問題の読み・条件を維持します。

検証は全10段階×3語数の1,200問を別実装の全漢字列挙でも解答例の成立を確認します。`alternative-fixtures.json` は旧JMdict単独では一候補だったのに、追加辞書で別解が現れる実例6問です。CIのブラウザ検証は実Worker、手動別解チェック、モバイル表示、保存・印刷を対象とします。

## ネットでの確認

公開Web版の検索API・検索UI連携は廃止済みです。辞書の収録範囲で候補を照合し、未収録語や別解の不存在・唯一解を保証しません。回答の正誤判定機能は追加しません。
