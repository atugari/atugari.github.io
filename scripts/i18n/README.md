# ナンプレ帳の翻訳

公開先: https://atugari.github.io/nanpure/  
対応する言語は日本語を含めて20言語です。`languages.json` に選択肢と各言語の自称をまとめています。追加言語は Italiano、Nederlands、Svenska、Polski、Čeština、Русский、Bahasa Indonesia、Tiếng Việt、ไทย、हिन्दी、العربية。日本語原文をキーとします。

## 更新元

- `catalog.json`: メイン画面、ゲーム、ヘルプ、ヒント、印刷、管理、APIのエラーに共通で使う従来8言語の辞書。
- `inline-messages.json` / `inline-fixtures.json`: 強調や改行を含む文の全文テンプレート、文脈別の子要素の訳、元HTMLの検証例。
- `patch-notebook.mjs`: 動的な原文を翻訳前に保持し、数字と単位を全文で処理するための再生成可能なソース修正。
- `runtime.js`: 動的なDOM、アクセシビリティ属性、タイトル、ネイティブダイアログ、キャンバスの翻訳と元の日本語への復元。
- `locale.ts` / `locale-context.tsx`: React側との連携。翻訳済みの文字を再解釈しないよう、Reactが出力した訳と原文の対応を渡します。
- `intentional-japanese.json`: 日本語クロスワードの入力例として原字が必要な2文。説明自体は各言語に訳しています。
- `exclusions.json`: HTMLの切れ端、変換表、重複する既存外国語など、表示原文として扱わない抽出候補と理由。

古い機能の英語だけの辞書登録が、レビューした他言語の訳を消さないように統合します。選択言語の訳が無いときに英語へ落とす挙動は使いません。未登録の文は診断対象として原文を残し、`NPI18n.missing()`で確認できます。

ユーザーが書いた名前・お問い合わせ・検索条件・保存セット名、問題の数字と解答、日本語クロスワードの単語とカギは内容を保持します。クロスワードの操作、設定、ルールの説明は翻訳対象です。

## 動的な文章

`{r}`・`{c}`・`{0}`などの値を文章全体の中で置換します。数値計算の結果は一つの値として扱い、計算式の演算子を文字列の区切りにしません。行・列・枠、印刷の紙の枚数・印刷面数・冊子ページ数、候補の除外条件を区別します。

正規表現で文を照合するときは全文一致とし、隣接して区切りの無い値を推測で分割しません。必要な行／列、紙／面、初期数字の有無などは具体的なテンプレートに分けています。一文字だけの単位と単純な座標は数値に限定して照合します。パターンの優先順位は、プレースホルダー名を除いた固定文字数で決めます。数字と単位の間に空白がある場合も、1問の単数形を優先します。

強調付きのルール説明と印刷の選択件数は、登録したセレクター・元の全文・子要素の種類が一致したときだけ、全文の訳に合わせて同じ子要素を並べ直します。子の数値・強調・改行を保持し、日本語への復元にも元のノードを使います。リンク、入力欄、Reactが管理する要素はこの再配置の対象外です。テキストは常にテキストノードとして挿入します。メモなどの入力内容は保持し、そのaria-labelとplaceholderだけを翻訳します。

## 検証と再生成

```sh
node scripts/check-nanpure-i18n.cjs /path/to/node_modules/linkedom
node scripts/export-nanpure.mjs /path/to/nanpure-source
```

DOMの翻訳、19外国語の有無、日本語の意図しない残存、プレースホルダー、言語往復、数字、入力内容の保持、印刷、各HTMLページを検査します。GitHub Actionsでは、この検査に加えて日本語の9画面で公開APIの読み込みを確認し、8言語×4画面を390px幅で表示・はみ出し検査します。さらにジグソーの作成手順を8言語×4種類の領域複雑さで操作し、難易度選択、問題数の単数形、最終確認を検査します。印刷は8言語×3条件（通常印刷の答えなし・あり、分割印刷）でプレビュー、枚数、読み上げラベルを確認します。外国語レイアウトの検査には応答が一定のテストデータを使い、ランキングや問い合わせを送信しません。

新しい原文候補を調べる場合:

```sh
node scripts/i18n/extract.cjs /path/to/nanpure-source /tmp/nanpure-string-audit
```

候補には連結HTMLや内部データが含まれるため、実際に表示される文と照合します。`catalog.json`を更新してから再生成してください。エクスポーターはこのディレクトリの辞書とランタイムを毎回組み込むため、旧ソースの部分翻訳には戻りません。

## 追加言語と画面の向き

`additional/` は言語別の翻訳です。オフラインの Argos 英語→対象言語モデル（CTranslate2 4.8.3）を下訳に使い、主要な操作・表示設定・基本ルールなどの修正を `additional-overrides.json` に分けています。専門の母語話者による全文章の校閲を示すものではありません。翻訳品質が不十分だったウクライナ語・トルコ語は選択肢にも配信パックにも含めていません。モデルや変換用Python依存関係は配信しません。訪問者の操作・入力内容を翻訳サービスに送信しません。

`build-additional-translations.py` は英語カタログの抽出JSON、モデルの展開先、キャッシュ先、下訳先を引数に取る補助ツールです。出力は直接公開せず、プレースホルダー・数字・記号・ファイル名、用語とルールを確認してから辞書に取り込みます。モデルのダウンロード元はArgosの公式パッケージ一覧です。確定した辞書はGitで管理し、通常のエクスポートではPythonやモデルを必要としません。

アラビア語は `dir="rtl"`、その他は `dir="ltr"` に切り替えます。盤面・候補メモ・数字パッドの座標順は左から右に固定します。`language-layout.css` を外枠と問題帳の両方に組み込みます。印刷SVGの数字も座標と元の値を保ちます。

```sh
PLAYWRIGHT_MODULE=/path/to/playwright CHROME_BIN=/path/to/chromium \
  node scripts/check-nanpure-languages-browser.cjs .
```

追加11言語について、375px幅でホーム・通常プレイ・自由に遊ぶ・表示設定・印刷SVGを操作します。言語を往復しても入力した数字とセルのDOMノードを保つこと、選択した辞書だけを読み込むこと、iframeが親の辞書を再利用すること、アラビア語でも盤面が反転しないことを検証します。
