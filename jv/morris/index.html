Apa iku Mill (Nine Men's Morris)?

Mill (Nine Men's Morris) iku salah sawijining game papan paling tuwa ing donya, wis dimainake luwih saka 2.000 taun. Wong loro nuduhake papan sing ana 24 titik, disambungake nganggo garis. Saben pemain duwe sangang bidak — sisih siji ireng, sisih liyane putih — lan tujuane prasaja: jejerake telung bidak sampeyan supaya bisa njupuk bidak lawan sampeyan, nganti lawan sampeyan meh ora kari apa-apa.

Game iki ana rong perangan. Kapisan sampeyan nyelehake bidak sampeyan, siji-siji, ing titik kosong. Banjur, yen kabeh bidak wis ana ing papan, sampeyan nggeserake ing sadawane garis menyang titik kosong ing sakiwa-tengen. Rasane prasaja, nanging saben nyelehake iku penting: bidak sing diselehake kanthi sembarangan ing wiwitan bisa angel dilindhungi mengko.

Ing Pare Asobi sampeyan bisa main Mill gratis ing browser sampeyan, ing telpon utawa komputer sampeyan. Ora ana sing perlu didownload lan ora perlu nggawe akun — mung bukak game lan wiwit main.

Carane main

  1. Kaping pisanan, selehake bidak sampeyan. Giliran nyelehake siji bidak ing titik kosong. Ireng mlaku dhisik. Terusake nganti kesembilan bidak saben sisih ana ing papan.
  2. Gawe mill kanggo njupuk bidak. Nalika telung bidak sampeyan jejer ing garis sing nyambung, sampeyan wis nggawe mill, lan sampeyan bisa njupuk siji bidak lawan sampeyan saka papan. Sampeyan ora bisa njupuk bidak sing ana ing njero mill — kajaba kabeh bidak lawan sampeyan ana ing mill.
  3. Banjur obahake bidak sampeyan. Yen kabeh wis diselehake, geser siji bidak saben wektu menyang titik kosong ing sakiwa-tengen ing sadawane garis. Mill sing digawe kanthi obah uga ngidini sampeyan njupuk siji bidak lawan sampeyan.
  4. Kari telung bidak? Sampeyan bisa mabur. Nalika sampeyan mung kari telung bidak, sampeyan ora diwatesi maneh ing titik sing cedhak — sampeyan bisa mabur menyang titik kosong endi wae ing papan.
  5. Carane menang. Sampeyan menang kanthi nyuda lawan sampeyan dadi rong bidak, utawa kanthi ngeblok supaya dheweke ora duwe langkah sing kari. Yen posisi sing padha muncul kaping telu, utawa yen ora ana mill sing digawe sajrone 50 langkah, game rampung seri kanthi otomatis.

Rong versi: Mill klasik lan Morabaraba

Mill klasik (Nine Men's Morris) dimainake nganggo sangang bidak saben sisih, ing papan 24 titik sing diterangake ing dhuwur.

Morabaraba iku versi 12 bidak saka game iki. Saben pemain duwe rolas bidak, lan papan entuk papat garis diagonal tambahan. Bidak uga bisa obah diagonal, lan telung bidak jejer ing diagonal uga nggawe mill. Main luwih cepet lan luwih terbuka tinimbang game klasik, lan menehi ganjaran kanggo mata sing tajem kanggo garis diagonal.

Kaloro versi kasedhiya ing game sing padha. Sampeyan bisa ngalih ing antarane nalika sampeyan miwiti game anyar.

Cara main

Main online karo wong ing saindenging donya. Wiwit game cepet lan ketemu lawan anyar langsung. Main online duwe rating, pangkat lan penonton, kanthi telung kacepetan: biasa (30 detik saben langkah), alon (2 menit saben langkah) lan layang (24 jam saben langkah).

Main nglawan komputer. Ana telung tingkat komputer — gampang, biasa, lan kuwat — dadi sampeyan bisa sinau aturan miturut irama sampeyan dhewe banjur ngadhepi lawan sing luwih angel.

Main karo rong pemain ing siji piranti. Bareng-bareng nganggo siji telpon utawa siji layar karo kanca lan giliran nyelehake lan ngobahake bidak, kaya papan nyata.

Game iki kasedhiya ing 100 basa. Game iki nganggo basa sampeyan, lan sampeyan bisa ngowahi saka setelan kapan wae.

Pitakonan sing asring ditakokake

Apa Mill (Nine Men's Morris) gratis? Iya. Mill ing Pare Asobi gratis kabeh kanggo dimainake, ora perlu ndhaptar lan ora perlu nginstal aplikasi.

Apa aku bisa main ing telpon? Iya. Game iki bisa digunakake ing telpon, tablet lan komputer, langsung ing browser sampeyan.

Apa iku mill? Mill iku telung bidak sampeyan sing jejer ing garis sing nyambung. Nggawe mill ngidini sampeyan njupuk siji bidak lawan sampeyan saka papan.

Apa iku Morabaraba? Morabaraba iku versi 12 bidak saka Mill, kanthi papat garis diagonal tambahan ing papan. Obahan diagonal lan mill diagonal diidini.
