遊び方・操作・設定

横一列をそろえると消えます。2列以上の同時消し・連続消し・Tスピンで相手におじゃまを送り、最後まで残れば勝利。同じ対戦では全員に同じ順番でブロックが出ます。
友達とは人数と合言葉を同じにして「合言葉で対戦」。指定人数がそろうと自動開始。通信切断・退室は脱落となり、入り直すと次の対戦に参加します。合言葉が空なら新しく作ります。2人戦は2勝先取。再戦は全員がボタンを押すと始まります。
←→：移動 / ↓：下へ / ↑・X：右回転 / Z：左回転 / Space：DROP / C・Shift：HOLD / P：練習の停止。対戦中は一時停止できません。

外部のゲームライブラリ不使用。対戦はサーバーへ接続します。
