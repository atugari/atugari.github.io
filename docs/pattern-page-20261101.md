# 模様づくり専用ページ（2026.11.01.75）

利用者の録画で、小さなモーダル内の盤面がクリックやスクロールに伴って大きさを変え、操作や文字が小さい状態を確認しました。

- 通常の画面遷移 `flow: pattern` に変更。前の画面へ戻れ、保存後は問題の確認画面へ進みます。下書きの保存形式は保持します。
- PCの盤面は600px以上、スマホは330px以上。狭い画面は盤面だけを横に動かせます。説明や操作文字は16px以上、数字は28px以上です。大きさボタンでさらに拡大できます。
- 横長画面は道具・盤面・作成状態と見本を3列に配置。中幅は2列、スマホは1列とし、保存操作を盤面の直後に置きます。
- フッター位置に基づく縮小、状態変更後や描画終了後の再計測、ResizeObserverの連鎖を除去しました。サイズを決めるのは画面サイズの変化と明示的な大きさ操作だけです。
- マスの押下・遷移アニメーションを無効化し、ふりがなの有無でも見出しの高さを確保します。表示中の盤面は見本選択や白紙への変更でも自動スクロールしません。

確認：Cloud Browserで専用ページの表示、戻る、クリック前後の同一座標・同一サイズ、1910×878相当と390px幅の配置、16px以上の文字、問題プレビューと保存を確認しました。

CIでは既存の描画・対称・数字抜き・保存・再読込に加え、1910×878・1440×1000・390×844・320×740で、最低サイズ、通常表示とふりがなONの各フレームの盤面座標、見本選択時の安定性、大きさボタンとリセット、モーダルがないことを確認します。
