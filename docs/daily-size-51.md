# 2026-10-25以降の日替わり

日本時間2026-10-25以降は9×9以下とし、やさしい・ふつう・むずかしいの3段階とパズルの種類のローテーションを維持する。16×16・12×12の枠は9×9になる。2026-10-24以前の問題・記録・ランキング計算の盤面サイズは変更しない。

補充処理は、今後21日という補充範囲に限らず、保存済みのすべての未来の大盤面割当を列挙する。解が一つで元の難易度段階に合う問題を生成・検証してから、同じ日付・段階の割当を条件付きで原子的に置換する。生成に失敗した場合、古い問題は削除しない。開始済みの問題は入れ替えずエラーとして知らせる。使っていない大盤面ストックは退役させる。置換後に未来の大盤面が0件であることをDBで確認する。
