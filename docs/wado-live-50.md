# 印刷の常時プレビューと公開通知

印刷設定はプレビューと同じ画面で調整する。スマホは上下、PCは左右に配置し、設定欄だけをスクロールする。大きさ・文字・ヒント・用紙の4項目を切り替え、用紙の収録数を実測して自動更新する。A4全体と1問拡大を切り替え、直前の設定に戻せる。印刷ボタンは設定位置に関係なく表示する。

和同開珎は紙で解くための試作であり、一般向けプレイは未公開のままとする。開発履歴は内部記録に残すが、一般向け履歴と通知対象から除外する。ビルド番号と公開お知らせの番号を分離し、内部更新では新着を表示しない。過去に既読としたビルド番号が公開お知らせ番号より大きい場合も再通知しない。
