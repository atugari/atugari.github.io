# サイズと掲載項目から自動でA4を配置

手動の「1ページの問題数」を外し、問題の大きさ（45・55・70・90・120mm）、説明の文字サイズ・太さ、ヒント、余白、掲載項目を先に選ぶ形にしました。生成する総問題数は別の設定として維持します。

見出し・説明、名前・日付、問題番号、難しさと熟語数、管理番号、フッターは個別に掲載を選べます。管理番号は既定で非表示。サイトの管理番号は答えを表示しない安定したハッシュです。問題用紙の中央は空欄です。

アプリ・PC版とサイトで同じpaper.js / paper.cssを使用します。印刷と同じCSSで実寸のDOMを測り、希望する盤面寸法を保ちながら列数と行数を決めます。ヒントの長さや文字の太さによって高さが変わる場合も各行を測定します。1問も収まらない設定は縮小や欠落でごまかさず、設定変更を案内して印刷を止めます。

画面文字の200%拡大、紙の175%拡大、追加の太字線幅を抑えた漢字表示は引き継いでいます。古い問題帳は掲載項目等に既定値を補って読み込めます。

確認：AndroidとWindowsで5つの問題サイズ・標準と最大の説明文字・問題/解答/ヒントの組み合わせを実機WebViewで検証。項目非表示の省スペース配置、重複や欠落、空欄、ページ内の収まりを確認し、OSの印刷・A4 PDFを検証します。サイトは同様の組み合わせを公開前CIで検証します。
