# 漢字穴埋め 2026.10.23.46 / 印刷帳 2.2.0

ヒント候補を自動で用意し、問題ごとに1つ選ぶ形へ変更。視点そのものを指定する設定は設けません。分野・種類・意味に加え、連想・使う場面・働きや用途・特徴・対比を表示します。難しめ・ふつう・やさしめは手がかりの具体性による目安で、感じ方には個人差があります。

既存の571語の基本説明を保持し、日常語50語を追加。235語に705件の独自の別視点ヒントを用意しました。新規生成では3つの難しさすべてで追加ヒントが出せる問題を選びます。直近の対象語を避け、同じ説明や同じ視点が連続しない候補を優先します。似た文章の候補も間引きます。語彙や生成条件によって候補が限られる場合は、生成を停止せず利用可能な候補へ戻します。

個別の選択を保存・読み込み・印刷に反映します。おまかせに戻すことも可能。問題に載せるヒントの難しさと、難しさ別ヒント用紙を用意しました。印刷には候補を選ぶ操作部品を載せず、選択した文章だけを載せます。回答・採点のプレイ入口はありません。

サイトの新規問題は形式version 3。問題の10段階はアプリ・PC版と同じ使用頻度と語彙ランクに基づく条件を使い、ヒントの難しさとは分けました。旧version 1・2は元の条件・読み・選択肢のデータをそのまま検証できるように保持。端末の保存問題を書き換えたり削除したりしません。既存問題の文章ヒントは収録された語がある場合に表示します。

検証：全10段階×3語数の1,200問、回答漢字の混入防止、候補の視点、直近の対象語回避、視点の切替、個別選択の保存、ヒント無し印刷と3種類のヒント用紙。Androidのネイティブ画面・印刷ダイアログ、Windows実行ファイル・A4 PDFは専用CIで確認します。サイトの全体チェックはPages公開前のCIで実行します。
