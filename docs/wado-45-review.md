# 漢字穴埋め v2026.10.23.45

出題候補を手作業の2,045語に限定する方式を改め、3系統の固定辞書から抽出した87,353表記をすべて処理します。同じ表記と読みを2系統以上で確認した41,858語を採用、一系統だけの41,984表記と読み未確認の484表記を保留、読みの抽出条件を満たさない3,027表記を出題対象外としました。全件の結果・理由・読み候補・出典を配布物のwado-audit.tsvに記録します。保留・対象外は「存在しない」という判定ではありません。

未収録かどうかを無制限に探す代わりに、国立国語研究所『日本語教育のための基本語彙調査』（1984）のCC BY 4.0公開データを、範囲が固定された外部比較基準として使います。漢字二字の見出し2,590表記から、送り仮名が別記された語幹だけの15表記を別記し、送り仮名が空の行を持つ2,575表記を全件照合しました。数詞や珍しい原表記を後付けで削ったり修正したりしません。

対象2,575表記中、辞書で確認できたもの2,568（99.7%）、出題採用2,509。残る7表記も「現在の辞書では未確認」として記録します。これは現代の日常語全体の網羅率ではありません。wado-coverage.jsonには対象全件・対象外15表記・結果・出典を記録します。元資料の利用条件・ファイルハッシュ・抽出方法はscripts/wado/README.mdとsources.lock.jsonを参照してください。

生成は唯一解を必須条件にせず、成立する別解を認める方針に揃えました。画面と印刷は「解答例」と表示し、読み・選択肢も解答例に対するヒントと明示します。ネットで別解候補が見つかっても印刷選択を維持します。画面でのプレイ入口は引き続き準備中で無効です。Tavilyの自動検索はアカウント未接続のため無効のままです。

既存の保存形式version1は、旧語彙・読み・難度をlegacy-v1.jsonで保持して検証・表示します。新しい問題はversion2です。端末の保存内容やバックアップを書き換えず、旧リストは新規出題制限に使いません。

ローカル検証：全10段階×3語数の1,200問で解答例の成立、形式、ヒント、重複回避を検証。旧公開版で生成した全30条件の問題について、更新後の検証・読みとヒントの一致・データ不変を確認しました。辞書処理・外部比較の6単体テスト、19言語の追加訳、ネットUIのDOM連携テストも成功しています。実ブラウザでも、旧版で保存してから新版へ移動し、問題・読み・選択肢が保たれることを確認しました。全ブラウザ・4種の印刷レイアウトの最終CIはPRで実行します。
