# 模様づくりの固定表示と一画面表示（2026.11.01.76）

利用者の録画では、ページをスクロールするたびに盤面や道具の一部が隠れていました。模様を描くページの上に3つの表示方法を追加しました。

- 通常表示：従来の大きな盤面で編集し、ページ全体をスクロールします。
- 盤面を固定：盤面の位置を保ち、左右の道具や見本だけを個別にスクロールします。大きさは手動で調整できます。
- 一画面に収める：使える画面の幅と高さから盤面の大きさを自動調整します。ページ全体はスクロールしません。

初回は一画面表示。選んだ表示は端末に記憶します。スマホの固定・一画面表示では、下の「描く道具」「作成・保存」「見本・設定」で操作欄を切り替えます。作成可否は盤面の上に常時表示します。説明と操作文字は16px以上を維持し、狭く低い画面では通常表示に戻して拡大することもできます。

盤面のサイズを再計算するのは、画面サイズ・表示方法・明示的な大きさ操作を変えたときだけです。作成状態や道具欄の高さは計算に使いません。見出し・切り替え欄・状態欄の高さを確保し、ふりがなを付け直す間も盤面を動かしません。下書き、数字抜き、対称描画、取り消しとやり直し、問題の保存は継続します。

確認：実ワーカーの数理検証は33問と121ケース＋32変形を通過。Cloud Browserで390×740と320×636の全マスへの到達、最後のマスを塗る・元に戻す・作成欄への切り替え、ふりがな有効時の同一座標を確認。1916×784相当の横長表示も確認しました。

CIでは従来の描画・保存・再読込に加え、5種類の画面で一画面表示、パネル切り替えとスクロール、固定位置、明示的なサイズ変更、ふりがな処理中のフレームごとの盤面座標を検証します。
