# 模様づくりの操作改善（2026.11.01.74）

自由に遊ぶ画面と作成方法の選択画面に、マスの絵が付いた直接の入口を設けました。

描いている間は数字を隠して模様に集中でき、「できた問題を見る」で数字の並びを確認できます。プレビュー上で誤って描き換えることはありません。見本は実際のマスクを小さな図で示し、スマホには見本に移動するボタンも付けました。

標準の道具は最初に触ったマスに合わせて塗る／消すを決め、なぞった範囲に同じ操作を続けます。塗るだけ・消すだけも残し、取り消しに加えてやり直す操作を追加しました。見本の選択や白紙への変更も戻せます。

ふりがなの表示処理がクリックの伝播前に装飾を外すため、文字をクリックした場合にボタンを見失う問題がありました。模様づくりの入口とダイアログはイベントのcomposedPathから元のボタンを取得します。

スマホは描画・設定部分だけをスクロールし、作成可否と保存ボタンを別の領域に固定しました。保存欄が盤面に重なる配置は使いません。下書きの形式と唯一解の検証処理は引き継いでいます。

## 確認

- Cloud Browser：PCと390pxの画面で、絵付き入口・見本への移動・タップで塗る／消す・取り消し・やり直す・数字入りプレビューを確認。
- ふりがなONで、ボタンのruby要素を直接クリックして問題プレビューに切り替わることを確認。
- CIの既存ブラウザ検証に320px、プレビューの誤描画防止、ふりがな付きクリック、やり直す、保存欄と盤面の非重複を追加。
- 過去の公開リリースは変更せず、新しい配布用リリースを追加。
