# 漢字穴埋めの文字拡大・太さ調整

画面の説明、ヒント候補、ボタン、設定名、問題番号を標準・125%・150%・200%から選択。紙の説明、ヒント、解答文は標準・125%・150%・175%を独立して選択できます。設定は既存の問題帳に保存し、以前の保存データには標準を補います。

文字を大きくした印刷では収録数を減らし、文字を縮めずに紙面に収めます。ヒントなしの問題は元の詰め込み設定を利用できます。画面倍率は紙面やマスの文字の太さに連動しません。

アプリ・PC版2.3.0では同梱Bold書体への追加線幅を、旧最大2.1から基準サイズ0.5に下げています。字の大きさに比例させ、最小サイズでも太りすぎないようにしています。以前のheavy設定も新しい上限で表示します。サイトの漢字は従来どおり700の太字で追加の縁取りをしません。

Android・Windowsで最大設定の画面、問題・解答・ヒントの紙面、保存、A4 PDFと印刷を検証します。サイトは同じ拡大設定と保存、紙面の収まりを公開前のブラウザテストで検証します。
