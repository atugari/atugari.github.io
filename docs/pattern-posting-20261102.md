# 模様の描画道具と問題の投稿・共有（2026.11.02.83）

## 描画道具の追加

- 未公開の83版に、全面白・全面黒・白黒反転、直線、四角の枠と塗り、四方向につながる同色領域の塗りつぶしを追加。
- 対称をラジオボタンで直接選択し、左右・上下・上下左右・点対称に対応。新しい線や形にも同じ対称条件を適用する。
- 1マス移動と中央寄せ。端から出るマスは消え、元に戻せることを表示。
- 線・四角のドラッグ中は、その時点の始点と終点でプレビューし、前のプレビューを残さない。指を離した後に1回で元に戻せる。
- キーボードでは形の始点と終点をSpace/Enterで指定。Ctrl/Cmd+Z、Ctrl+Y、Ctrl/Cmd+Shift+Zで元に戻す・やり直し。
- 道具と条件を「描く道具」「作成条件」に分ける。白・黒と対称を上に配置し、基本画面の操作数は増やさない。
- 道具・色・対称を下書きと一緒に復元。生成済み・生成中の別の問題の模様と条件は変更しない。
- 図形、塗りつぶしの境界、移動、1回の取り消し、プレビュー更新、キーボード操作、復元、生成ジョブの保持を実際のUI処理でも検査。
- PCと320×636の表示で操作とレイアウトを確認。ブラウザーのドラッグで直線9マス、キーボードで四角の枠8マス、内側の塗りつぶしで9マスになること、通常の問題生成まで確認。

## 投稿と共有の変更

- 「問題を投稿・共有」から、X・LINEの投稿画面を開ける。本文を編集でき、初期数字と盤面の形だけを含む問題リンクを渡す。
- Xを開くときは、対応するブラウザーで問題画像のコピーも試みる。貼り付けが必要で、自動添付・自動投稿とは表示しない。
- 対応端末の共有機能は問題画像のみを渡す。画像共有に対応しない端末は本文と問題リンクを渡し、共有機能自体がない端末もX・LINE・リンクコピーから進める。
- 保存・画像コピーは詳細欄に整理。リンクコピーが拒否されたときは選択済みのリンク欄を表示する。
- 共有された問題を /nanpure/share.html で表示し、同じ問題を再共有・画像保存できる。解答、プレイ途中の数字、メモ、ユーザー情報をリンクに含めない。
- 更新履歴に、完成した模様ナンプレは唯一解を確認済みであることと、難易度を下げる場合も唯一解の条件を保つことを明記。

## 検証

- 模様ナンプレ33問を別の解答数判定でも確認し、すべて唯一解。
- 混在サイズ、負の方向から組み合わせて正規化した配置、8盤面・25×25を含む共有リンクの往復と不正入力の拒否。
- 実際の共有処理を、OS共有・クリップボードの制御可能なアダプターで検査。X/LINEの本文・URL、画像コピー、画像のみの共有、テキストのみの共有、機能なし、コピー拒否、共有取消・失敗を確認。
- ブラウザーで生成→共有→リンクから同じ問題を表示→再共有を確認。Xへの遷移と未ログイン時のログイン画面も確認。実投稿は行っていない。
- ふりがなによる投稿文ラベルの縦崩れと、共有ページのスタイルが画像プレビューへ漏れる問題を修正。
