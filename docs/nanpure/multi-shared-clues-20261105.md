# マルチナンプレの初期数字と共有依存の検証

## 300個の4×4で不足していた初期数字

各盤面を右下の1マスで順につなぐと、物理的なマスは `300 × 16 − 299 = 4,501` 個になる。難易度1では65%を四捨五入した2,926マスに数字を置く。旧方式は子盤面の2種類の数字を丸ごと消して別解を作っていた。4×4では1盤面につき8マスを使うため、先頭に最大15個、ほかの299面に最大8個ずつ置いても2,407個にしかならない。少なくとも519個足りず、完成盤面の探索を始める前に終了していた。

新方式は、2種類の数字を入れ替えても行・列・枠・追加ルールを保てるマスの集まりを求める。共有マスを含む集まりだけを空けると、同じ数字の別のマスを初期数字として使える。盤面を切り離すと共有マスの値が変わる具体的な別解を、先頭を含む全盤面で検証する。生成を確定する前に全体の初期数字数（難易度1・2）、指定された論理解法、独立した解数検査を通す。

## 2面で確かめる例

通常4×4を2面用意し、Aの右下とBの左上を1マスだけ重ねる。`.` は空欄。初期数字は合計20個で、31マスの65%を四捨五入した条件を満たす。

| 行 | A | B |
|---|---|---|
| 1 | `..34` | `....` |
| 2 | `3412` | `3412` |
| 3 | `2.4.` | `..43` |
| 4 | `4.2.` | `4321` |

4×4の全288通りの完成盤を照合すると、A単独は2解で右下が1か3、B単独も2解で左上が1か2になる。両方に入る数字は1だけ。結合した問題についても、独立した解数検査で1解、候補が1つに絞られたマスの確定だけで最後まで解けることを確認した。

## 配布用ファイルでの回帰試験

`node scripts/check-nanpure-mixed-multi.cjs --all-counts` で347問を実生成した。4×4の1マス重ね・難易度1は2〜300面の299通りをそれぞれ検査した。盤面ごとに全288通りの完成形を列挙し、初期数字が一致する完成形の中で共有マスが別の値を取ることを確認した。共有マスの数字が一致する完成形だけをつないで数えると、どの面数でも全体の解は1通りだった。

15サイズ、9×9で選べる6ルール、問題全体の難易度1〜5、自由配置、3面以上の重なり、循環、300面の格子を含む。各組み合わせは代表例を検査した。論理ソルバーの旧版との比較920件も判定差は0件だった。`.100` でプレイ途中の保存例は、元のID・入力・メモ・旧形式の証拠を含めて復元し、再圧縮したデータも一致した。

390×844のChromiumで、1マスも重ならない2面は「盤面Bから盤面Aへつながっていません」と表示し、「作る」を無効化した。生成Workerの起動は0回だった。300個の4×4をつないだ正常ケースは、実際の生成ボタンからWorkerで生成し、自動保存・再読み込みまで実行した。ID `AkmhO`、初期数字2,926個、共有依存300面、解数1、仮置きなしを確認した。保存内容のSHA-256は再読み込み前後とも `f05d8bb4b6ad6882d2d7830a57b1f5d54d32c65fb3cd113447c5467656f36cfa`。この1回の計測ではWorkerへの送信から応答まで100.7 ms、生成の確認操作から保存完了画面まで340.1 msだった。

旧版の4×4・300面・難易度1の時間はエラーになるまでの値。改善版の各実行では対象のIDで2,926個の初期数字、300面すべての共有依存、唯一解、仮置き不要の論理完解を確認した。難易度2の初期数字は1,890個、サイズ混在の難易度1は8,451個だった。旧版の面数欄は記録された証拠の件数を示す。

難易度5の300面での所要時間は旧版 1.49〜2.07秒、改善版 1.29〜4.35秒。探索の途中で論理解法の難度が合わず、別の完成盤からやり直す場合がある。生成時間と最大RSSには盤面数だけでなくサイズ、重なり方、探索した回数も影響する。

### 再現方法

リポジトリのルートで実行する。各コマンドを実行するたびに新しいプロセスで1回計測し、結果をJSONで出力する。条件名は `pair4`、`chain4`、`chain4L2`、`mixed`、`rules`、`cycle`、`lattice`、`high`、`large`。予算は通常15秒、300個の25×25だけ120秒。

```sh
source_path=nanpure/releases/2026.11.05.101/notebook/mixed-multi.js
old_source=nanpure/releases/2026.11.05.100/notebook/mixed-multi.js
node --expose-gc scripts/bench-nanpure-shared-clues.cjs "$old_source" chain4 S1
node --expose-gc scripts/bench-nanpure-shared-clues.cjs "$source_path" chain4 S1
```

計測した改善版生成コードのSHA-256は `34c09f02307e25132d7583dc2e05f8522d3e1ecdb74cd85f969478e87a9afa33`。
