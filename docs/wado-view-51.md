# 和同開珎の閲覧入口と検索機能の廃止

ナンプレ帳の試作メニューから、和同開珎の問題を開ける。中央の空欄を見て頭の中や紙で考え、難しさ別ヒントと解答例を確認する。回答入力・答え合わせ・採点・正解記録は設けない。問題帳と印刷は引き続き利用でき、閲覧中の問題・ヒントの表示状態は同じバックアップ対象データ内に保存する。

ネット検索の画面、外部検索リンク、自動検索、接続確認、サーバー実装、検索用設定を削除した。旧APIはDBや外部サービスへアクセスする前にHTTP 410を返す。過去のクライアントがそのURLを呼んでも検索されない。

この変更を「回答できるようになった」という公開通知にはしない。今回の一般向け告知は日替わりサイズの変更に限定する。
