# ナンプレ帳 GitHub Pages 版

公開先: https://atugari.github.io/nanpure/
旧リンク https://atugari.github.io/nanpure.html も同じ画面へ移動します。

## 2026.10.21.27（現在）

日替わり・ランキング・カレンダー・お問い合わせ・クラウド保存をCloudflare APIへ切り替えました。
既存のGitHub PagesのURLとブラウザ保存先は維持しています。オンライン機能も同じ画面で使えます。
クラウド保存は秘密の引き継ぎコードで別の端末と接続します。第三者ログインやR2は不要です。
管理画面は `/nanpure/?view=manage`。管理用キーは公開リポジトリに保存しません。
旧サーバーの挑戦記録・問い合わせ・過去の日替わり問題は、所有者の承認後にCloudflareへコピーしました。
移行前に重複と衝突を調べ、移行後に全項目の一致を確認しています。既存データは上書きせず、元データも旧サーバーに残しています。

APIの構成・テスト・定期補充は `nanpure-api/README.md` を参照してください。

## 更新手順

検証済みのオンライン版チェックアウトと、その依存関係・ビルド結果を用意し、次を実行します。

```sh
node scripts/export-nanpure.mjs /path/to/nanpure-online
python3 scripts/enhance-nanpure.py .
node --experimental-vm-modules scripts/check-nanpure-pages.cjs /path/to/linkedom
```

`nanpure/releases/<version>/` に版ごとのアセットを書き出します。公開中のプレイを妨げないため、過去の版のフォルダは削除せず、プレイ中の自動リロードもしません。GitHub Actionsは既存の他のゲームをそのまま組み立て、ナンプレの全ファイルのSHA-256を公開前に検証します。

API・データベース・秘密情報・サーバーの問題データは公開しません。クライアント配布コードの難読化とソースマップ除去はオンライン版と共通です。ブラウザに配布するコードや以前の公開履歴のコピーを完全に防ぐものではありません。

音源・ライブラリの出典は各アセットに同梱しています。
音源は `nanpure-audio/<version>/` の分割データに含めています。公開ビルド時に復元し、SHA-256を検証してGitHub Pagesから配信します。閲覧時の復元処理やオンライン版への依存はありません。BGMは再生時まで読み込まず、初期設定はOFFです。

## 確認済み

- 出力されたReact画面の起動、自由に遊ぶ→戻る、メニュー、日替わり・お問い合わせ・ランキングのリンク。
- GitHub Pages上に存在しないAPIを初期読み込みで呼ばないこと。
- 23種類のルール選択と戻る操作、配布後の生成エンジンと元の生成結果・一意性の一致。
- シルプレ660問と大型225問の改訂データ、バージョン付きアセットの参照先とハッシュ。
- 音源の分割データからの復元を外部通信なしで検証。公開する全120ファイルのSHA-256が検証済みデータと一致。

DOMテストは実機での画面サイズ、IME入力、音声出力、印刷結果を保証するものではありません。
