# パレあそびへのパズル移動（2026-10-30）

公開先は GitHub Pages の `/plaza.html`。既存のデザインを保ち、シルプレ・和同開珎・クロスワード・クロスてんびん・天秤・しるしのこみち・シルプレ工房・試作室へのカードを追加。

- `/puzzles/` が移動したルールの一覧。各入口は `/puzzles/<rule>/`。
- 問題の生成・プレイ・印刷は既存の検証済みエンジンを同一オリジンで読み込む。版は `/nanpure/version.json` から解決し、更新に追従する。
- 元データ、問題番号、保存キー、IndexedDB、生成履歴、旧リリースは移動や削除をしない。同じブラウザなら既存の途中経過を読む。
- ナンプレのホーム拡張（`nanpure/collection/entry.js`）が `/puzzles/navigation.js` を読み込み、非ナンプレの入口を移動案内に置き換える。ナンプレの自由プレイ内も同じアダプターを適用する。単独生成・一括生成とも、クロスてんびんをナンプレの新規選択から除く。既存問題・生成キューは保つ。
- 既存10万問のカタログと全パックは変更しない。ナンプレ帳では22ルール93,660問を表示。クロスてんびん6,340問は `/puzzles/cross/stock/` で表示する。元IDと途中記録は共通。従来の `/nanpure/collection/?p=<クロスのID>` は移動先に転送する。
- ナンプレ派生（キラー、ジグソー、おとなり、ステップなど）はナンプレ帳に残す。
- まほうじんは既存の生成・保存機能のみ。イラストロジックを含め、未完成のプレイ機能や未公開の推理パズルを公開していない。
- Sites の試作版は変更していない。

確認: 217条件のナンプレ絞り込み、既存カタログの100,000件と93,660/6,340への分割、ルート整合性・保存キー不変更・公開リリース方針・全ファイル整合性。管理プレビューではシルプレ練習入力、和同開珎の保存問題生成、クロスワード起動、クロスてんびんの収録盤面と移動先リンクを確認。HTTPプレビューでは既存ナンプレシェルが secure-context 専用 crypto.randomUUID に依存するため、シェル全体と再開の検証は HTTPS を使う隔離CIテスト `check-pareasobi-move-browser.cjs` で確認する。
