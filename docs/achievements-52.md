# 称号コレクション（2026.10.24.52）

ナンプレ帳のホームとメニューから開く1,000個のコレクション。候補一覧のNP-0001〜NP-1000を固定IDとして使用する。名前と条件の原本は `scripts/achievements/catalog-source.json`。生成は `python scripts/achievements/build-catalog.py`、公開用クライアントの組み立ては `node scripts/prepare-achievements-release.mjs`。

- 明記600件・抽象300件・完全秘密100件。未獲得の完全秘密は投影した公開表示だけで検索・絞り込みし、名前・条件・進捗を渡さない。獲得後は真の条件を表示する。
- 6段階のレア度は条件に基づく目安で、実際の所持率とは分ける。コレクションは36件ずつ描画する。
- クリアは正しい盤面の完了経路から記録する。自動完成・解答表示は対象外。同じ問題の再開や解き直しはSHA-256の問題識別情報で重複を防ぐ。誤入力の履歴が分からないプレイで無誤入力称号を付与しない。
- 和同開珎は閲覧・生成保存・ヒント表示・有効な印刷プレビューだけを記録する。回答入力・採点・クリアの機能は加えない。
- 印刷条件は有効なプレビューを指す。印刷機への出力成功を推測しない。作問条件は生成後に端末保存が成功した問題を指す。
- UTCの獲得時刻を保存し、日本時間で年月日と秒まで表示する。確認できない過去の達成や日時は推定して付与しない。導入前のプレイを初見や無誤入力として読み替えない。
- 獲得と通知待ちを先に保存する。ホーム・日替わりの選択画面へ戻って1秒以上落ち着いた後に右下へ4.2秒表示する。プレイ・ランキング挑戦中・設定や確認の画面・印刷・生成・バックアップ中・非表示タブでは表示しない。途中で安全でなくなった通知は隠して待ち行列へ戻す。1回の滞在で最初の2件を個別表示し、残りはまとめる。音とフォーカス移動は使わない。
- 通知は通常・控えめ・なし。ブラウザーの動きを減らす設定にも従う。
- 獲得・途中経過は `np-achievements-v1`、集計参加用の秘密IDは `np-achievement-identity-v1`。両方を既存のファイル／クラウド引き継ぎ対象に加える。同一オリジンのフレームは親の記録処理に集約し、対応ブラウザーではWeb Locksを使って複数タブの競合を防ぐ。

## 所持率

既定では集計に参加しない。参加を選んだときだけ秘密IDと獲得済みの称号番号を送信する。サーバーはIDをハッシュ化し、名前・問題・入力履歴を受け取らない。`POST /api/achievements` は既存のX-Cloud-Key形式を使用する。ID単位で登録をまとめ、複数回同期しても分母や同じ称号の所持数は増えない。全1,000称号を導入したカタログ版1を同期した保存データが共通の分母となる。

表示名は「集計に参加した保存データの所持率」。実人数とは言い換えない。分子・分母・更新日時を表示する。集計がない場合は未集計。オフライン時は最後に取得した日時付き集計を使う。参加をやめると以後の送信を停止する。端末の集計キャッシュは引き継ぎの必須データにしない。

D1マイグレーション `0005_achievements.sql` は既存の問題・挑戦・クラウド保存を変更せず2つの表と索引を追加する。旧 `/api/wado/web-search` は引き続き410で終了し、検索サービスには接続しない。
