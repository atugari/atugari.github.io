保存・読み込み・使い方

このHTMLファイルをブラウザで開くだけで使えます。生成と印刷にインターネット接続は不要です。画面での解答・採点はありません。

問題はこのブラウザに自動保存します。ファイルを移動したり、別のブラウザで開いたりする前に、下のボタンから保存してください。

問題を開くと、現在の問題帳が置き換わります。読み込み前に確認できます。以前の試遊版の途中経過とは別の保存形式です。

紙で使うには

  1. 難しさ・熟語の数・問題数を選んで生成します。
  2. 問題の大きさ、説明やヒントの大きさ・太さ、用紙に載せる項目を選びます。A4の収録数は自動で決まります。
  3. 印刷プレビューを開き、「印刷・PDFに保存」を押します。
  4. 印刷画面ではA4縦・倍率100%を選び、ブラウザのヘッダーとフッターはオフにしてください。

難しさ別ヒントと解答例は別に印刷できます。問題帳の保存ファイルには解答例も含まれます。

辞書・ヒントの出典と利用条件

出題辞書：41,858語。ヒントは既存のクロスワード用の独自説明を利用し、場面・働き・特徴・連想・対比などの独自ヒントを追加しています。答えの漢字が説明に含まれるヒントは除き、視点を自動で分散させます。
