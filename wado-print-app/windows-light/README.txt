漢字穴埋め 印刷帳 2.6.0 — Windows軽量版

ZIP全体を展開して、WadoPrint.exe を開いてください。DLLやフォルダーも一緒に置いてください。

使い方・辞書・画面・印刷機能は2.6.0と同じです。「つくる」→「選ぶ」→「印刷」の順に使います。
画面での回答・採点はありません。答えは紙で考え、各自で確認してください。
既存の問題帳と設定は同じ保存先を使います。設定から問題帳をファイルに保存できます。

Windows 10（1903以降）/11・64ビット向けです。Windowsに含まれる.NET Framework 4.8以降を使用し、巨大な.NET 8ランタイムの同梱を省いています。
表示にはMicrosoft Edge WebView2 Runtimeを使用します。未導入の場合は、Microsoft公式サイトからインストールしてください。
https://developer.microsoft.com/microsoft-edge/webview2/

データ、フォント、SDKの許諾文は同梱の licenses.txt にあります。
